## Before you push

```bash
just test
just lint
```

`just test` runs the unit suite (`uv run pytest tests/unit`). It never touches Docker or
the network.

`just lint` runs `ruff check`, `ruff format --check`, and `mypy` over `armasec_lite`.

`just fmt` auto-fixes what `ruff` can fix.

## The documentation site

The docs site lives in `docusaurus/` and is built with Docusaurus, the shared
`@vantagecompute/docusaurus-theme`, and `@vantagecompute/docusaurus-plugin-pydoc` (a git
submodule at `docusaurus/vendor/docusaurus-plugin-pydoc`) for the autogenerated
[API Reference](./api-reference/index.md).

```bash
just docs-dev
```

Runs the Docusaurus dev server with live reload.

```bash
just docs-build
```

Builds the static site into `docusaurus/build`, including regenerating the API reference
from `armasec_lite`'s docstrings.

```bash
just docs-serve
```

Serves the built site locally.

```bash
just docs-typecheck
```

Type-checks `docusaurus.config.ts` and `sidebars.ts`.

```bash
just docs-diagrams
```

Parses every mermaid diagram in the docs with mermaid's own grammar, so a malformed diagram
fails the build here instead of rendering as a blank box in a reader's browser.

```bash
just docs-verify
```

Runs `docs-build` and `docs-diagrams` together, then checks that the generated API
reference has one page per module declared in `docusaurus.config.ts`.

## Conventions

**Match the surrounding code.** Comment density, naming, and structure should be
indistinguishable from what is already there.

**Comments explain *why*, never *what*.** A comment earns its place by recording a
constraint that is not visible from the code itself, not by restating the line beneath it.

**Commit messages** follow Conventional Commits.
